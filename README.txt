วิธีเพิ่มบทเรียน

1. เปิด content/<ชื่อวิชา>/
2. ใส่ไฟล์ .html, .htm, .md, .markdown หรือ .txt
3. รีเฟรชเว็บ — ระบบจะค้นหาบทใหม่อัตโนมัติ รวมถึงโฟลเดอร์ย่อย
4. ลำดับบทดูจากชื่อไฟล์ เช่น 01-, 02-, 03-
5. HTML ใช้ <title> เป็นชื่อบท หรือใช้ชื่อไฟล์ถ้าไม่มี title
6. Markdown ใช้หัวข้อ # เป็นชื่อบท

ตัวอย่าง:
content/math/01-บทที่-1.html
content/math/02-สมการ.md
content/math/03-แบบฝึก/04-โจทย์.txt
